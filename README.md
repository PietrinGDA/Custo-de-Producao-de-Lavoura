# Custo-de-Producao-de-Lavoura
Sistema publicado: https://petrix666.pythonanywhere.com/

Aplicativo para controlar os custos de produção de soja ou milho, registrando despesas por hectare, como sementes, fertilizantes e defensivos. Também calcula o custo da produção e o ponto de equilíbrio, indicando quantas sacas são necessárias para cobrir o investimento.
